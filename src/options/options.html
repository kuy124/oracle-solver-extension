How it works

1. On an assessment page the extension reads the question + choices.
2. It checks your local answer key (instant).
3. If missing and AI is enabled, three models vote on the answer and it is cached.
4. The floating panel shows the suggested choice; press Apply to select it.
5. With Autopilot on, steps 1–4 repeat automatically and each answer is submitted.
